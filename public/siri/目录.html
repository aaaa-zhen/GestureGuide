苹果 Siri / Apple Intelligence 逆向研究

基于 iOS 27 / macOS 26 系统私有框架的符号分析，用单页 HTML 讲清苹果端侧 AI 的设计 · 每篇自包含、浏览器直接打开。下面按「看到的 → 怎么做的 → 凭什么出彩」三段顺着读最顺。

一 · 你看到的 — 答案长什么样
01从一句话到一张卡片
生成式 UI：大模型吐带标签的文本，渲染器按封闭标签集画成卡片 + 四级降级兜底。一切的「出口」。
二 · 它怎么做到的 — 看屏、打通、认识你
02识屏是怎么做到的
它怎么看懂屏幕：识别被前置成写入，结构化实体 + 缓存 + 检索；含问屏、图片内容、跨应用执行。
03App Intents 打通了什么
它怎么动你的应用：端云模型分工、第一方开放到什么程度、第三方怎么接、大数据怎么不崩、多任务编排。
04Personal Context
它怎么认识你：此刻上下文 → 个人画像（知识图）→ 习惯记忆（行为引擎）→ 凭证（安全芯片）。
三 · 凭什么出彩 — 全局与细节
05Siri 架构全景
把上面串起来：两百多个框架分成六层，从模型到产品；含开发 / 产品两个视角。
06容易忽略的出彩细节
没人会专门夸、缺了却很难受的 8 个小处：可打断、多设备仲裁、主动建议时机、危险操作确认、不确定追问、输出护栏、语气控制、不逐字打字。
07看与听 · TTS 深挖
同一份内容为眼睛和耳朵分别优化：显示版 / 朗读版分开写、韵律控制、神经合成管线（时长 → 声学 → 声码器）、嗓音分代（Compact / Natural / Neural）、Personal Voice 端侧录入、流式边生成边念、按场景决定该不该出声。
仅供研究学习 · 符号反映接口结构，不含内部实现细节
