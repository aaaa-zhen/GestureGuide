Personal Context

苹果怎么「认识你」——从此刻的处境，到关于你的画像，到你的习惯，再到你最敏感的身份资产 · 基于系统私有框架的符号分析

一条主线：越往里，越是「你」，保护越重

「Siri 懂我」背后其实是一整套叫 Personal Context 的体系。它不是一团模糊的「记住」，而是四个由浅入深的圈层：最外是此刻（这一秒的处境），往里是你是谁（关于你的长期画像），再往里是你做过什么（习惯与记忆），最核心是你的身份资产（驾照、钥匙、银行卡）。

越往内层，数据越敏感，苹果的保护就越重——从「用完即弃」一路加码到「锁进独立安全芯片」。这篇顺着这条线讲清楚。

第一层 · 此刻

上下文：临时的「环境」

你正盯着一条订单消息，说一句：「把它存下来」。——光这句话根本没法办：「它」是什么？存到哪？

能办成，是因为 Siri 不只听你这句话，还看了你「此刻」的处境：屏幕上正开着哪条消息、你前一句说了什么、现在几点在哪。把这些当下的线索一起看，「它」才有了着落。这就是「上下文」——它专门补全你话里省掉的东西。线索来自三处：

屏幕上有什么
你正看着哪条消息、哪张照片、哪个航班——「它」「这个」指的就是屏上那个。IntelligenceFlowContext（识屏）
刚刚聊了什么
上一句的来龙去脉——「再来一个」「也发给他」要接上文才懂。
此时此地
几点、在哪、正开着哪个 App——「现在」「在这」「用这个」靠它补全。ContextTypeAppInFocusBundleId

关键是：这些线索只描述「此刻」，主要服务于「这句话此刻在说什么」。它让 Siri 听懂当下——但它能记多久、记多少，是下面这个常见疑问。

「我开了空调，聊了别的，再问『刚才让你干了啥』，它记得吗？」

这要分两种「记得」，结论很不一样：

✓ 接着上一轮
「开空调」→「调高一度」→「把它关了」——它知道「它」是刚才那台空调。这是多轮对话，确凿支持（ConversationHistory / previousResponse / Continuation）。它很擅长接着说。
⚠ 回头翻旧账
中间聊了一堆不相关的，再回头问「刚才让你干了啥」要它复述——更可能记不全。对话记忆有窗口，插得越多、隔得越久，那一轮越容易掉出去。

有个反直觉的点：系统其实内部留着你执行过的动作（actionHistory），但那是给预测 / 建议 / 隐私设置用的（还能一键清除），没有证据表明做成了「对话里你一问、它念回一串你刚才的操作」这个功能。所以——

它擅长「接着说」，不擅长「翻旧账」。会话记忆偏短、偏「紧接刚才」；要它跨越一堆闲聊回溯老操作，多半已经不在窗口里了。「真正长期记得你」的，不是上下文，是下面的画像和行为记忆。

第二层 · 你是谁

个人画像：持久的「关于你」

第二层是跨场景、长期攒下来的「关于你」。它不随这一句话变，是一张持久的图——落地是 CoreKnowledge，一个本地知识库。

① 里面到底有什么

它不存散文本，而是把「关于你」拆成结构化的三元组（CKTriple，「主-谓-宾」），按一套本体（CKOntology）连成一张图。符号能证实它装这几类：

人与关系
你的联系人、家人、同事，以及他们之间的关系标签（familyMember / relationshipLabel）。
地点
家、公司、常去地（配合 CoreRoutine 的位置规律）。
历史事件
沉淀的时间线——你长期做过什么。CKHistoricEvent
App 交互
你和各 App 怎么打交道、常用哪个干什么。CKAppInteractionsContext

② 这些信息从哪来

不是它去翻你的数据，而是各 App / 系统主动「捐献」（donate）进来——这是苹果一以贯之的机制。你建个联系人、发条消息、到了某地，相关 App 把这件事 donate 给系统，沉淀进图（事件流落在 Biome 端侧存储）。全程本地（localOnly），不上传。

③ 它不只是「存」，还会「替你提前想到」

画像最值钱的，不是它记得什么，而是它能替你想到你没说的。这些事你从没专门告诉过它——是它从你的行为里自己算出来的：

  • 每天 18 点你都从同一栋楼出发回家——它没问过你家在哪，但「该走了，路上有点堵」会在 17:50 自己冒出来。
  • 有个人你天天发消息、每张合照都有——它没被告知这是你伴侣，但 ta 的消息会优先提醒、来电不被勿扰拦。
  • 你常去的那家咖啡馆、爱听的歌单——周末早上打开手机，它恰好摆在那。

这背后是几套从行为里推断的机制（都是实挖的符号，不是它翻你资料）：

推断关系
不靠你填，从交互信号反推——RelationshipInferenceAgent / FamilyInference。「谁和你亲」是算出来的。
算「谁重要」
ImportantPerson + ConfidenceLevel——评出对你重要的人并带把握程度，自动当 VIP 对待（优先、不打扰拦截）。
亲密度打分
AffinityScore——给人、地点、照片量化「你有多在意」，越在意越往前排。

所以画像是活的、会自己长：你越用，它越懂你在意什么、越能在你开口前把对的东西递过来。「懂你」的真正价值，不在于它知道你的人际关系，而在于它替你把本该自己操心的事提前办了。（这套推断可关：relationshipInferenceDisabled。）

④ 也让它「听懂你省略的话」

③ 是主动替你想到；这张图还有个被动的用处——你说话时省掉的东西，它能查图补上：

  • 把口语补成具体目标——「提醒我下班路上买菜」「导航回家」，「下班路上 / 家」是哪，要查图才知道。
  • 顺着关系多跳找——「给我老板的助理发邮件」，沿「你→老板→助理→邮箱」走两三跳（CKPath）。这种关键词搜索做不到。
  • 同名挑对人——通讯录里三个「张伟」，结合关系和你平时找谁，挑出最可能那个。

它最关键的设计：只切一小块

这么私密的一张图，不会整张丢给模型。每次请求只用 EntitySubgraphService 切出和当前相关的子图注入——问妈妈就取家庭那一小块，不暴露你的全部关系网。

两层的本质区别就此清楚：上下文是「此刻的环境」，临时、用完即弃；画像是「持久的你」，跨场景沉淀、可推理。前者让 Siri 知道你在什么情境，后者让它知道你是谁。

第三层 · 你做过什么

习惯与记忆：苹果早有一套「行为引擎」

这一层最容易被想成「ChatGPT 那种记住你说过的话」。但苹果不是这么设计的。它的记忆不是为大模型新造的，而是复用了沉淀多年的行为学习引擎，几个框架各管一摊：

📊
CoreDuet CDInteraction · AdviceEngine
交互事件流：你和设备 / App 的每次交互记成一条 CDInteraction，建议引擎从历史推断「接下来你想做什么」。
📍
CoreRoutine CRKLocation · PatternNetwork
学地点与作息规律：家、公司、通勤、常去地。「我到家了」靠它。
🕸️
CoreKnowledge CKHistoricEvent
沉淀成历史事件时间线 + 三元组事实，持久（永久事件 vs 会过期的临时事件）。
🔮
CorePrediction feedbackLearning
变成预测 / 排序，每次交互再回灌（donateInteraction 按 scoreWeight 加权）形成闭环。

关键认知：苹果的「记忆」本质是「行为统计 + 预测」，不是「对话存档」。它记的是你做了什么、有什么规律，不是把你说的话原样存下来。

它会「遗忘」——而且是刻意设计的

符号里有明确的半衰期衰减：decayAllAppActionLaunchSequencesWithHalfLifeInDays、decayConstant。

久不做的行为权重指数下降、被淡忘，最近的占主导。个人化跟着你近期习惯漂移，不被很久以前的一次行为绑死。记忆是一条带遗忘的滑动窗口，不是只进不出的账本——这也顺带是隐私（不无限堆积你的一切）。

「随口说一句，它记得吗？」

按苹果的设计，主路径是隐式（从行为学），不是显式（听你陈述）。知识库有 assertFact（断言一条事实）这个口子，但整套引擎的重心明显在观察行为。

用苹果的设计语言说：它更像一个「行为分析师」——默默看你做什么、找规律、做预测；而不是一个「记笔记的秘书」把你口述逐条记下。「随口一句记成长期规则并主动应用」不是这套系统的主设计意图，接口层也看不到这条专门链路。

第三层 · 补充

它到底用什么「学」

顺带回答一个常见疑问：学你习惯，用的是深度学习吗？答案是混合，而且很克制——能用便宜的统计就不上神经网络：

启发式 + 衰减
最基础的「常用 / 最近」排序——计数 + 半衰期。ActionPredictionHeuristics
贝叶斯（经典 ML）
行为预测打分用概率回归，不是深度学习。BayesianProbitRegressor
深度模型（CoreML）
更复杂的建议 / 语义预测才上神经网络，跑在神经引擎。CoreSuggestionsML · ANECompiler

而且它能在设备上做真训练，不只推理：MLUpdateTask（端侧再训练）、PersonalizedModel（个性化模型）、FederatedLearning（联邦学习——只上传聚合梯度、不传原始数据）。

所以「学」也是分层的：便宜场景用统计 / 贝叶斯，复杂场景上深度学习；个性化靠端侧训练 + 联邦学习——越用越准，数据却不出端。苹果的风格：不为用深度学习而用，但该上的地方不含糊。

第四层 · 你的资产

凭证：最敏感的「你」，锁进芯片

最内层，是「你」的硬核部分——身份资产。「我的驾照在图库吗？」不在。你拍的照片才在图库；Wallet 里的数字驾照存在独立安全芯片里，iOS 和图库都碰不到。而且不止驾照，这一档装着一批最敏感的东西：

🔒 高安全 · Secure Element
驾照 · 身份证 · 车钥匙 · 门禁 · 银行卡 · 交通卡
  • 存进独立安全芯片，和 iOS / 图库物理隔离
  • 带 NFC，碰一下付钱 / 开门 / 过闸
  • 出示要 Face ID + 你同意
  • 带硬件认证密钥，可被验证为真
📄 普通 pass
登机牌 · 门票 · 会员卡 · 优惠券
  • 本质是带签名的文件（条码 / 二维码）
  • 展示用，不进安全芯片
  • 扫一下就行，一般不要 Face ID
  • 只是「可信地展示信息」，安全性低得多

分界就一句：用来「证明 / 支付 / 开门」的进芯片，只用来「出示」的是文件。

高安全那档，怎么守

SECURE ELEMENT（独立芯片）
驾照 · 银行卡 · 车钥匙 · 交通卡
原始数据 + 硬件密钥
▲ 硬件边界 · iOS 跨不过去 ▲
iOS / App / 图库 · 只能「请求」，拿不到原始数据
物理隔离
存在 Secure Element 的 applet 里（appletIdentifier / CredentialStore），系统拿不到原始数据。
授权 + 选择性披露
每次出示要 userConsent + Face ID；买酒只回答「是否满 21」（ageOver），不暴露生日 / 住址 / 证号。
离线 + 丢失可控
expressMode 没网甚至关机也能刷；deviceLost 可远程挂起，捡到的人也读不出。

对比图库：图库存的是驾照的一张照片（像素，谁进相册都能看、整张暴露）；Wallet 存的是一份凭证（带硬件密钥、要授权、可选择性披露的身份本身）。一个是像素，一个是身份。

四层合起来，就是 Personal Context 的全貌——一条「越往里越是你、保护越重」的递进：

此刻
上下文——临时、用完即弃，解「这句话在说什么」。
你是谁
三元组画像——持久、本地、可推理，解「他 / 妈妈是谁」。
你做过什么
行为引擎——统计 + 预测、带遗忘、端侧学习，越用越懂。
你的资产
凭证——锁进安全芯片，授权 + 选择性披露，最高保护。

它不是「记住了你说的每句话」，而是把你的此刻、关系、习惯、身份，分层存好、按需取用、逐层加锁。

懂你靠的是结构化的图、带遗忘的学习和芯片级的隔离——不是一个无限长、什么都往里塞的档案。
