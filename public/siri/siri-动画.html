Siri 的动画

发光球怎么动、聆听 / 思考 / 说话怎么切、球怎么变成面板——Siri 不止「流式吐字」一套动画 · 基于系统私有框架的符号分析

大家熟悉的 Siri 动画是回答时「逐字浮现」（那套在生成式 UI 篇讲过）。但那只是其中一套。从系统里翻出来，Siri 至少还有：发光球（Orb）、状态切换、球↔面板的形变、色差焦散的视觉底子、发送飞入。这篇把这些动画各讲一段。

一 · 主角

发光球 Orb：不是一个圆，是物理 + 粒子 + 辉光

新版 Siri 的形象是个发光球（Orb）。它看着简单，其实是几层叠出来的（框架 SiriUI，符号 SiriOrb）：

OrbGlowView
辉光层——那圈柔光、晕染就是它。
OrbParticleConfig
粒子层——球不是死的，里面有粒子在流动 / 翻涌。
SiriOrbPhysicsInternal
物理驱动——不是放预制动画，是按物理实时算形变 / 回弹，所以动得「有生命感」。
SiriOrbRegular / Small
尺寸态——常规态、缩小态（如收到岛上 / 角落）之间会形变过渡。

它会随你说话起伏（符号里有 amplitude 音量、deformation 形变）：你声音大它涨、停顿它缩，像在「听」。这种「活」的感觉，来自物理 + 音频驱动，不是循环播放一段视频。

这和你逆向过的那套 GLSL（siri-shader-reverse 里的声波 / 流体光球）其实是同一个东西的两面：苹果端上是 Orb 的 glow + particle + 物理，你在 shader 里复刻的是它的色散辉光与 metaball 融合。视觉语言一致。

二 · 状态

聆听 / 思考 / 说话：一台状态机

Orb 不是一直一个样——它跟着 Siri 的状态变（符号 SiriState / SiriStateChange）。每个态有自己的动法，态之间是平滑过渡：

外加 idle（待机）、dictation（听写）等态。「它现在是在听、在想、还是在说」，你一眼就能从球的动态读出来——这是状态机给的，每个态视觉上可区分。

三 · 形变

球 → 面板：一次连续形变

Siri 要给你看卡片 / 文字时，那个球不是消失再弹出面板，而是「长」成面板——符号 SiriGlowToPlatter（发光球 → platter 承板）。球摊开、化成回答的底，是一次连续形变，没有生硬的切换。

这跟生成式 UI 那套是接续的：球形变成面板 → 面板里的内容再逐字 / 逐块流式浮现。从「一个球」到「一张卡」，整条是连贯的一镜到底。

四 · 视觉底子

色差与焦散：那层「高级感」从哪来

Orb 和液态玻璃看着「高级」，靠的是几个刻意加的视觉效果（不是凑巧）：

ChromaticAberration
色差 / 色散——边缘那层彩色折光。符号里有专门的 filter / kernel / 校正曲线，说明是当成风格主动加的，不是镜头缺陷。
caustics
焦散——光透过 / 反射形成的亮纹，液态质感的来源。
JiggleAnimation
Jiggle 抖动——元素轻微回弹 / 抖一下的反馈（带时长 / 数据），让交互有弹性。

这套色散 + 液态，正是你在 liquid-glass.html 里复刻的那套——苹果在 Orb、Liquid Glass 上用的是同一组视觉原语。

五 · 发送

发送 / 附件飞入：连「飞过输入框那一刻」都管

你发消息 / 发附件时，气泡飞入、附件飞向目标，也有专门的动画控制器 SendAnimation（区分 AttachmentKind 卡片 / 媒体、有 Backdrop 背景层）。它精细到编排「附件飞过输入框的那一刻」——这种没人会注意、但少了就觉得「廉价」的细节。

附

一个历史注脚：全屏边缘光 iOS 18 旧版

上一代（iOS 18）的 Siri 唤醒，是屏幕四周亮一圈彩色光（符号 edgeGlowBlur / edgeGlowOpacity / ScreenEdge）。新版已经换成了 Orb 发光球，边缘光是历史形态——这里记一笔，免得和现态混。

Siri 的动画不是「一个会动的图标」，是一套连贯系统：球涌现 → 随你说话起伏 → 形变成面板 → 内容流式浮现。

每一段都有专门的物理、状态、视觉机制在背后——动得自然，是算出来的，不是放视频。
